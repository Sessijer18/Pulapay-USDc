Référence — Motion

Motion Reference

Chaque animation a une raison fonctionnelle. Jamais pour décorer. Toujours respecter prefers-reduced-motion.

⚡
Tap Feedback
dur-xs: 100ms · ease-out
Scale 0.96 au press. Retour immédiat au tap. Hover sur desktop uniquement.
✓
Success Confirm
dur-lg: 400ms · ease-spring
Scale 0→1 avec léger overshoot. Célèbre sans excès. Une seule fois.
→
Screen Transition
dur-md: 250ms · ease-out
Slide horizontal. Avant = droite. Retour = gauche. Direction logique.
Skeleton Pulse
1.4s · ease-in-out · infinite
Shimmer doux sur le solde et les transactions en chargement. Jamais de spinner seul sur le solde.
↑
Page Entry Reveal
dur-lg: 400ms · stagger 50ms
Éléments slide-up + fade-in en cascade. Un seul moment orchestré par écran à l'entrée.
⚠
Error Shake
300ms · ease · une fois
Shake horizontal ±4px sur OTP faux ou solde insuffisant. Signal physique sans surprise.
/* Framer Motion — patterns Pulapay */

// 1. Entry animation (stagger children)
const container = { hidden: {}, show: { transition: { staggerChildren: 0.05 } } }
const item = { hidden: { y: 14, opacity: 0 }, show: { y: 0, opacity: 1, transition: { duration: 0.4, ease: [0.16,1,0.3,1] } } }

// 2. Success pop
const successAnim = { scale: [0, 1.15, 1], rotate: [-10, 3, 0], transition: { duration: 0.4, ease: [0.34,1.56,0.64,1] } }

// 3. Always respect reduced motion
const { prefersReducedMotion } = useReducedMotion()
const animation = prefersReducedMotion ? {} : successAnim
R.02
Référence — Implémentation

Implementation Rules

Règles non-négociables pour implémenter le Design System Pulapay correctement.

RègleDétailRaison
Un CTA orange maxUn seul btn-primary visible par écranHiérarchie d'action claire, pas de confusion
Touch target 44pxTout élément interactif : min 44×44pxAccessibilité mobile · iOS HIG · Android guidelines
Montants formatés247 500 FCFA — toujours avec séparateurLisibilité · Évite les erreurs sur les gros montants
États de chargementSkeleton sur solde · Jamais spinner seulRéduit l'anxiété · Preserves layout
Idempotency UIDésactiver boutons après 1er clic de confirmationPrévenir les doubles envois
Erreurs humainesMessage en français, sans code techniqueConfiance utilisateur · "Réessaie" pas "Error 503"
Tokens onlyUtiliser uniquement les CSS vars / tokens TailwindCohérence · Facilite les futurs changements
prefers-reduced-motionToutes les animations vérifiéesAccessibilité · Certains pays ont connexions lentes
Safe areasPadding dynamique iOS / Android notchBottom nav pas coupé sur iPhone 15+
i18n readyAucune string hardcodée · tout en t()FR + EN + Fon dès le départ
